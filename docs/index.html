How The Engine Works

Six steps from data to a tracked pick. Systematic, repeatable, and on the public record.

// 01
DATA IN

Fresh data from many sources is brought together and refreshed automatically.

// 02
MODELING

Win probability comes from many independent models, blended into one view of each game.

  • Every game is simulated at scale
// 03
MARKET CHECK

Each view is checked against real market prices.

  • Prices that are only estimated are labelled as estimates
// 04
GRADING

Every pick is graded on probability and price. If there is no value, it is skipped.

  • Where it helps, a safer line may be locked, with the original line shown beside it
// 05
LOCKED BEFORE THE GAME

Picks are locked automatically and time-stamped before the game starts.

  • Anything locked late is flagged as late
// 06
SETTLE AND TRACK

Results are settled automatically from official sources and tracked live.

  • Wins and losses both stay in the record

// 06 — GRADING

Pick Grading System

Every model output is graded before it ever reaches you. Four tiers — each defined by win probability and expected value threshold.

PREMIUM

Highest-conviction — model sees a strong mathematical edge

WIN PROB  ≥ 67% EV  > +5%
OPTIMAL

High-confidence play with clear positive value at market price

WIN PROB  ≥ 62% EV  > +3%
LEAN

Moderate edge — situational value, smaller exposure advised

MODERATE WIN PROB SMALL VALUE EDGE
SKIP

Below model threshold — no pick

BELOW LEAN NO PICK
WHAT IS EXPECTED VALUE (EV)?

EV measures the long-term profit edge per pick. Positive EV means the model's probability exceeds the implied market odds — that line returns profit over time.

No LOCK language. No guaranteed picks. No hype. Just probabilities, edges, and grades — laid out transparently.

// 07 — PRINCIPLES

Built On Transparency

#
PUBLIC AND TIME-STAMPED

Every locked pick is public and time-stamped before the game.

EV
LOSSES STAY IN

Wins, losses and pushes all stay in the record. Individual picks are never removed to improve it; when a whole product is retired, its picks leave the live record.

$
REAL PRICES, LABELLED

The real posted price is shown. Estimated prices are labelled as estimates. Units and ROI appear only on prices labelled real or estimated.

±
ADJUSTED LINES, SCORED

A locked adjusted line shows the original posted line beside it, with a scorecard of how the posted line would have done.

A+
GRADES ARE PUBLISHED

The PREMIUM, OPTIMAL, LEAN and SKIP definitions are public. Skip is a valid output.

!
LATE LOCKS FLAGGED

A pick locked late is recorded and flagged as late. It still counts in the record.

↻
ONE LEDGER

The figures are generated straight from the same ledger the engine locks into. They are not hand-edited.
